# Компас — MVP 0.1 без API-ключа

Это первый **действительно запускаемый** прототип на Python/Streamlit. Он не притворяется настоящим ИИ: вопросы и проверка ответов предопределены, данные о вузах не обновляются автоматически. Цель — проверить пользовательский маршрут Георгия и инженерную основу продукта.

## Запуск (Windows PowerShell)

Для работы нужен установленный Python 3.10 или новее.

```powershell
cd kompas_mvp
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Если PowerShell запрещает активировать виртуальное окружение, не меняй глобальные настройки: запусти `.venv\Scripts\python.exe -m pip install -r requirements.txt`, затем `.venv\Scripts\python.exe -m streamlit run app.py`.

## Запуск (macOS / Linux)

```bash
cd kompas_mvp
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Откроется локальный адрес вида `http://localhost:8501`.

## Что проверить первым

1. Выбери «Георгий: выбор вуза».
2. Укажи год 2027, исторический интерес и карьерную цель.
3. На вопрос о бюджете ответь «Пока не знаю».
4. Заверши сценарий: приложение должно не исключать ни один вуз и предупредить о правилах 2027.
5. Открой «Тренажёр», сделай одну неправильную и одну правильную попытку.
6. Скачай отчёт Markdown (после завершения маршрута).

## Ограничения и честная демонстрация

- Языковая модель **не подключена**; API-ключ не нужен.
- Не проводит персональную оценку шансов поступления.
- Данные о приёме 2027 отсутствуют; ссылки 2026 — справочные.
- Два дополнительных сценария — рабочие контуры, ещё не проверенные с пользователями.
- Память ошибок существует только во время сеанса; постоянная память и PDF — задачи следующей версии.
