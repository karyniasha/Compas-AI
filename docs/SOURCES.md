# Источники и правила работы с фактами — MVP 0.2

Дата подготовки: 22.10.2026.

## Контракт

Исходные записи находятся в `kompas/data/facts.json`; парсер, валидатор и режим чтения — `kompas/knowledge.py`. Поля: `fact_id`, `subject_type`, `university`, `program`, `topic`, `statement`, `value`, `intake_year`, `source_url`, `retrieved_at`, `valid_until`, `verification_status`, `notes`.

- Статус `verified` допустим только при наличии HTTPS-ссылки официального домена вуза, даты проверки и конца периода актуальности **записи**.
- `effective_status` понижает запись до `stale` после `valid_until`, при дате просмотра раньше `retrieved_at` и при несовпадении `intake_year` для правил поступления.
- `unverified` не выводится как установленный факт. Неизвестные баллы, цены и количество мест остаются `null` или просто отсутствуют.
- `valid_until=2026-12-31` — редакционная дата следующей обязательной перепроверки, **не официальный срок действия программы**.
- В режиме `programs` наличие учебной программы не эквивалентно подтверждённым условиям поступления в следующем году.
- В режиме `admission` справка кампании 2026 **не считается** действующей для 2027, даже если URL доступен.
- Не предусмотрен веб-скрейпинг при запуске или автоматическая независимая проверка веб-страниц: наличие `verified` означает ручную проверку источника **22.10.2026**.

## Добавление новой записи

1. Открой официальный источник, проверь конкретное утверждение в контексте программы и года.
2. Внеси запись в JSON с уникальным `fact_id`, URL и `retrieved_at`; для ежегодных правил задай `intake_year`.
3. Выбери редакционную дату `valid_until`; не выдавай её за установленный университетом срок.
4. Запусти `python -m unittest discover -s tests -v` и проверь представление в разделе «Источники».
5. Если утверждение не подтверждено — не присваивай `verified`.
