# Компас: технический эскиз MVP 0.1

## Зачем такой вариант

Контролируемое ядро Python не позволяет языковой модели самостоятельно изменять цель, последовательность обязательных шагов или превращать недостающие данные в цифры. Streamlit отвечает только за UI. Доменная логика в `kompas/core.py` полностью независима от Streamlit и проверяется тестами.

## Архитектура текущей версии

```
Streamlit UI (app.py)
    |
    v
Scenario Orchestrator (kompas/core.py)
    |                  \
    v                   v
Question State       Deterministic Case Evaluation
    |                   |
    +-------> Markdown Report
```

- Состояние хранится в `st.session_state`, **не на серверном диске**.
- Основной сценарий: Георгий, 17 лет, Саратов, история, СПбГУ / СГУ / РГГУ / МГУ.
- Два сценария для расширения: стажировка и первый месяц работы.
- `report_markdown()` намеренно не выбирает один университет и не выдаёт неизвестные цены или вероятности.
- Обучающий режим проверяет выбор из вариантов; никакого семантического оценивания ответов в версии 0.1 нет.

## Следующие этапы

1. Модель хранения подтверждённых сведений: `statement`, `university`, `program`, `intake_year`, `source_url`, `retrieved_at`, `valid_until`, `verification_status`.
2. Интерфейс `LanguageModel` для свободного диалога. Реализовать API-адаптер после получения ключа.
3. Выделить анализатор ответов с типизированным результатом и валидацией по рубрике; фактологические ответы разрешать только с привязкой к базе знаний.
4. SQLite для опциональной памяти прогресса с согласием пользователя и возможностью удаления.
5. Адаптация последующих кейсов по сохранённым ошибкам.
6. Экспорт PDF и запись демонстрации.
7. Автотесты на ошибки источников, отказ от выдуманных баллов, неизвестные финансы, смену года поступления, контроль полноты ответа.

## Критерии готовности MVP 0.1

- Пройти все шесть шагов Георгия без API-ключа.
- Выбрать «Пока не знаю» о финансах — ни один вуз не исключён.
- Год 2027 — отображается предупреждение, что материалы 2026 нельзя считать действующими условиями.
- Пройти пять обучающих кейсов; после ошибки список повторения пополняется.
- Скачать Markdown-отчёт.

## Структура каталога

- `app.py` — приложение Streamlit.
- `kompas/core.py` — сценарии, переходы, проверка тренировочных ответов, отчёт.
- `tests/test_core.py` — автоматическая проверка ядра.
- `README.md` — установка и запуск.


## Итерация 0.2 (22.10.2026)
Эта схема описывает версию 0.1. В новой сборке `app.py → knowledge.py → data/facts.json` обеспечивает информационный режим; `model.py` определяет интерфейс `LanguageModel` с детерминированным `RuleBasedModel`. Основной маршрут и экзаменатор по-прежнему работают через `core.py`. Подключений к внешнему API, постоянного хранилища и сетевого получения фактов нет.
