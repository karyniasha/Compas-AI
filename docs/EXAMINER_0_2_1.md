# Экзаменатор «Компаса» — версия 0.2.1
Дата: 26.10.2026. Задачи K-014–K-016.

## Что считается оценкой

Проверяется **только выбор одного из заранее заданных ответов**. Для каждого кейса `TrainingCase.correct` указывает индекс корректного выбора, `principle` задаёт педагогический критерий. Для каждого неправильного индекса `RUBRICS[(scenario, index)].incorrect_reasons` содержит проверяемое текстовое объяснение. Нельзя выдавать это за семантический анализ свободной речи или работу генеративного ИИ.

## Категории (постоянный код → пояснение)

| Код | Название |
|---|---|
| `evidence` | Проверка фактов и обещаний |
| `uncertainty` | Работа с неопределённостью |
| `tradeoffs` | Сравнение альтернатив |
| `agency` | Самостоятельность выбора |
| `constraints` | Учёт ограничений |
| `communication` | Коммуникация и ответственность |
| `safety` | Безопасность решения |

## Алгоритм обратной связи и повторения

1. Проверяется допустимость сценария, индекса кейса и индекса варианта; некорректный выбор отклоняется.
2. Если выбран корректный вариант, показываются `feedback` и `principle`.
3. Если выбран неверный вариант, показываются конкретная причина выбора, следующий подход (`feedback`), принцип и категория ошибки.
4. Повтор предлагается по всем кейсам с последней неправильной оценкой; дополнительно — ещё не освоенные кейсы той же категории **внутри текущего сценария**. Успешно завершённые кейсы повторно не рекомендуются.
5. В UI сохраняется последнее выбранное значение, статус и результат только в пределах сеанса Streamlit; перезапуск обнуляет их. SQLite не используется.

## Как проверять

Выполнить `python -m unittest discover -s tests -v`. Отдельные проверки охватывают все 11 кейсов и каждый вариант ответа, валидацию полноты рубрик и категорий, отсутствие рекомендаций для уже правильных ответов, отрицательные данные и сохранение объяснения при перерисовке заглушки Streamlit.

## Ограничения

- Категория назначается кейсу, а не выводится из произвольного рассуждения; разные неверные варианты могут иметь одну и ту же категорию.
- Повтор — простая детерминированная рекомендация, а не долговременная адаптивная модель.
- Результаты не сохраняются в SQLite и не передаются во внешние API.
- Рубрики — учебные эвристики. Они не предсказывают поступление, найм или успех на работе.
