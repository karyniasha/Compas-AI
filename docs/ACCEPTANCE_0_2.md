# Ручная приёмка MVP 0.2 на компьютере автора

Машинная проверка проекта: 18/18 тестов, синтаксис Python проверен. **Ручная приёмка UI пока не выполнена.**

1. Установить зависимости через `python -m pip install -r requirements.txt`, затем `python -m streamlit run app.py`.
2. Убедиться, что в боковой панели указано «MVP 0.2 · Локальный режим без API-ключа».
3. Выбрать «Георгий: выбор вуза», заполнить шесть этапов, год **2027**, бюджет **«Пока не знаю»**.
4. Открыть «Источники», «Программы»: увидеть четыре вуза, официальные ссылки и дату проверки; открыть ссылки.
5. Открыть «Условия поступления»: проверить, что **нет** утверждённых правил 2027; сведения 2026 находятся **только** в архивной секции.
6. Открыть «Расходы и проживание»: ни для одного вуза **не должно** быть выдуманных стоимостей, сумм и нулевых цен.
7. Открыть «Тренажёр»: сделать неверный и верный выбор, увидеть обратную связь и подсказку повтора.
8. Скачать Markdown-отчёт и проверить ссылки, даты, сохранение всех вузов и оговорку о правилах 2027.
9. Сбросить маршрут; аналогично завершить `internship` и `onboarding` и пройти по одному кейсу.
10. Проверить запуск после полного закрытия приложения. Прежние ответы **не обязаны** сохраняться: SQLite отсутствует.

Результат UI-приёмки фиксировать с указанием ОС, Python, Streamlit, даты, ошибок, скриншотов. Пока все пункты 1–10 не подтверждены человеком, не утверждать, что приложение проверено в реальном браузере.
