# Техническое ТЗ «Компаса» 1.0
Версия 1.0 · 22.10.2026 · цель: управляемое расширение MVP 0.1

## Стек
- Python 3.11+ целевая версия (текущий код заявляет совместимость с 3.10+).
- Streamlit 1.x — UI.
- Python-модули — маршрутизация, сценарии, валидация, генерация отчёта.
- SQLite — планируемые сессии, прогресс, память ошибок.
- JSON/SQLite — база знаний с обязательными датами и ссылками.
- Портируемый `LanguageModel`-адаптер; до получения ключа — `RuleBasedModel`/детерминированный режим.
- `unittest` — тесты без внешнего платного API.
- Markdown-отчёт сейчас; PDF-представление после проверки ядра.
- Git и `.gitignore`; секреты — только окружение/секретное хранилище.

## Текущее состояние фактического кода
- `app.py` — Streamlit.
- `kompas/core.py` — `SCENARIOS`, `get_question`, `save_answer`, `evaluate_case`, `report_markdown`.
- `tests/test_core.py` — пять unit-тестов.
- `requirements.txt` — `streamlit>=1.38,<2`.
- Состояние в `st.session_state`, **не** в SQLite.
- Информация о вузах не обновляется, свободного LLM-диалога нет; экзаменатор проверяет выбор ответов, не смысл произвольного текста.
- Доступные сценарии: `history`, `internship`, `onboarding`.
- Ручная проверка UI на машине пользователя ещё не подтверждена.

## Целевая схема
```
Streamlit UI
  -> Session Controller / Scenario Router
  -> Profile + Decision State
     -> Question Policy (детерминированные обязательные этапы)
     -> Knowledge Repository (подтверждённые данные и источники)
     -> LLM Adapter (опционален)
     -> Examiner + Rubrics
     -> Progress Repository (SQLite)
  -> Decision Report (MD/PDF)
```

### Принцип границ ответственности
Python решает: какие этапы обязательны, что считается пропуском, какие источники подтверждены, какие факты устарели, какие поля попадут в отчёт.
LLM помогает формулировать вопросы и анализировать свободные ответы, но не определяет итоговый вуз единолично и не «создаёт» университетские факты.

### Типы данных для источников
`fact_id`, `subject_type`, `university`, `program`, `statement`, `value`, `intake_year`, `source_url`, `retrieved_at`, `valid_until`, `verification_status` (`verified`, `stale`, `unverified`), `notes`.

Для поступления в 2027 году данные о правилах 2026 нельзя считать действующими без перепроверки. Неизвестное число — `null`, а не 0.

### Состояние пользователя
`session_id`, `scenario_code`, `stage`, `answers`, `criteria_weights`, `unresolved_questions`, `training_attempts`, `error_categories`, `consent_to_persist`, `created_at`, `updated_at`.

### Минимальный контракт адаптера (проектный)
`generate_followup(context, allowed_facts) -> structured_response`
`evaluate_free_answer(case, answer, rubric) -> structured_feedback`
Функции должны возвращать валидируемые структуры; UI не должен обращаться к конкретному API напрямую. Пока нет ключа — вызываем предсказуемый локальный путь.

### Данные и безопасность
- Не хранить реальную личную информацию без необходимости.
- Для персонализации достаточно псевдонима/локального ID; финансовые данные — диапазон или «не знаю».
- При постоянной памяти запросить согласие, предоставить очистку истории.
- Не отправлять секреты в репозиторий.
- Перед демонстрацией явно показывать, когда работает тестовый режим без LLM.

## Критерии приёмки следующей версии
1. Без ключа приложение запускается и проходит маршрут Георгия.
2. Неизвестный бюджет не исключает СПбГУ, СГУ, РГГУ или МГУ.
3. В отчёте отмечена необходимость перепроверить правила 2027.
4. Три сценария и 3–5 ситуаций на каждый остаются доступными.
5. Неизвестные баллы, цены, стипендии, общежития не генерируются.
6. Любой факт, показанный как подтверждённый, имеет URL и дату.
7. После реализации SQLite — ошибка сохраняется между перезапусками при согласии пользователя.
8. Markdown и PDF содержат версии источников, допущения и открытые вопросы.

## Адаптер LLM K-034 (27.10.2026)
- `kompas/llm_adapter.py`: `OpenAIResponsesModel` реализует существующий `LanguageModel`; импорт и конструктор не выполняют сетевых запросов. SDK `openai` импортируется лениво при явном вызове, устанавливается отдельно через `requirements-llm.txt`.
- Конфигурация: `OPENAI_API_KEY`, `OPENAI_MODEL` (оба обязательны для внешнего вызова). Фиксированный endpoint `https://api.openai.com/v1`, таймаут 15 секунд, без повторных попыток. Ключ не хранится в исходниках; исключения провайдера не выводятся и не логируются адаптером.
- `generate_followup(context, allowed_facts)`: год из `context["year"]`; входные `Fact` повторно валидируются, фильтруются по текущей дате и году. В Responses API передаются контекст как пользовательские данные, только допущенные факты с метаданными и локальный список шаблонов. Используются `instructions`, `text.format` с JSON-схемой и `store=False`.
- После исправления P1/P2 принимается только завершённый ответ без отказа с двумя полями: `template_id` из `FOLLOWUP_TEMPLATES` и `fact_id` (строка или `null`). Для `review_fact` требуется ID допущенной записи; для `programs`, `admission`, `costs`, `missing_information` требуется `null`. Схема и соответствие полей повторно проверяются в Python. Дополнительные поля и HTTP(S)-URL в идентификаторах запрещены; сравнение URL выполняется после `casefold()`.
- Текст `FollowupResponse` составляется в Python: локальный вопрос; для `review_fact` — также исходное утверждение, URL, год набора, даты и примечание разрешённой записи. Неизвестный год обозначается явно. Никакой произвольный текст LLM или утверждение из пользовательского контекста не подставляется в отображение. `used_fact_ids` содержит только фактически показанную запись, `mode="llm"` означает выбор шаблона моделью и обозначается в тексте.
- Отсутствие конфигурации/SDK, ошибки API, таймауты, отказ или некорректный ответ возвращают вопрос `RuleBasedModel`, `mode="rules"` и безопасное пояснение причины. Следующий явный вызов может снова попробовать API; глобальное состояние режима не хранится.
- `evaluate_free_answer` делегирует локальной модели, не отправляет ответ и возвращает `FreeAnswerFeedback(assessed=False, mode="rules", ...)`.
- Streamlit использует `RuleBasedModel` даже при настроенном окружении. K-033 отдельно добавит диалог и согласие. SQLite, PDF, исходные факты, рубрики и порядок сценариев не изменялись.
- Проверено 55 автоматическими тестами на Python 3.11.9 без SDK и сети, включая регрессии P1/P2 и запрет сетевых подключений в тестах адаптера; реальный API, качество выбора шаблонов и браузерная приёмка не проверены.
