## Важное разногласие
На втором вебинаре эксперт говорит, что прототип **не обязателен**, и что для демонстрации продуктовой эмпатии достаточно одной глубоко проработанной персоны. В более строгом варианте требований, ранее найденном на конкурсной странице, были указаны **работающий прототип, минимум три сценария, база знаний, архитектура** и функции Lead. Для защиты от риска пропуска формального критерия строим продукт по более строгому варианту, не жертвуя качеством сценария Георгия.

**Перед сдачей:** открыть страницу https://kids.sk.ru/skkidschallenge, проверить актуальные PDF/приложения, условия для категории Lead (19 лет), точное место отправки и формат файлов. Если сайт недоступен — запросить регламент у организаторов.

## Критерии качества по ранее изученному общему положению [С, проверить]
- Соответствие заданию
- Техническая основа
- Владение инструментами
- Наглядность и оформление
- Новизна и актуальность

Ранее упоминалась шкала до 20 баллов за каждый критерий. Не использовать эти значения как окончательные до сверки с актуальным официальным положением.

## Уточнение реализации K-034 (27.10.2026, [Н])
- R08/R09/R16: отдельный адаптер Responses API реализован с сохранением автономного режима. После исправления P1/P2 — 55/55 тестов с подменённым клиентом; реальная доступность API и качество выбора шаблонов моделью не проверены.
- R14: наличие API-ключа не включает отправку ответов из интерфейса. Вызов адаптера из Python явный; перед передачей пользовательских данных вызывающая сторона должна получить согласие. UI и согласие относятся к K-033.
- R06/R10/R15: LLM получает только предоставленные валидные факты с подходящим годом и сроком актуальности, URL и датами. Возвращает только выбор локального шаблона и необязательный ID источника. Python формирует текст из шаблона, а утверждения и метаданные берёт только из допущенной записи. Произвольный текст LLM не отображается, даже если сопровождается допустимым ID. Неизвестные шаблоны, посторонние ID, дополнительные поля и HTTP(S)-URL в идентификаторах любого регистра приводят к локальному возврату.
- R07/R11: оценки экзаменатора, рубрики и логика сценариев не меняются. `evaluate_free_answer` остаётся локальным и возвращает `assessed=False`.
