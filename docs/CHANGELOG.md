# Changelog

## 0.2.1 — 26.10.2026

- Реализованы K-014–K-016: 11 редактируемых рубрик (5 history, 3 internship, 3 onboarding), для каждого неправильного варианта — конкретное объяснение.
- Добавлен `kompas/examiner.py`: семь стабильных кодов категорий ошибок, результат `CaseAssessment` и детерминированные рекомендации повторов.
- Сохранён обратно совместимый интерфейс `evaluate_case()`. В UI результат сохраняется при последующих перерисовках **только в текущей сессии**.
- Markdown-отчёт включает категории ошибок и рекомендации, но не сохраняет историю между запусками.
- Добавлено 9 автоматических тестов: итого 27. Браузерная проверка обновлённой версии ещё требуется.
- Зависимости не изменены; SQLite, согласие и PDF остаются в плане.

## 0.2 — 22.10.2026

- Добавлены `kompas/knowledge.py`, `kompas/data/facts.json`, модель статусов и года поступления.
- Раздел «Источники» использует локальную базу, отдельно показывает архив и неизвестные сведения.
- Добавлен провайдер-независимый контракт `LanguageModel` и предсказуемый `RuleBasedModel` без API.
- Усилена валидация порядка этапов и уникальности критериев.
- Отчёт `history` включает редакционно проверенные URL, даты и ограничения.
- Добавлено 13 тестов (итого 18), включая headless smoke без установленного Streamlit.
- Добавлены аудит и инструкция для ручной приёмки.

## 0.1 — 22.10.2026 (входящая версия)

- Streamlit UI, три сценария, 11 кейсов, временная память последнего результата, Markdown-отчёт и 5 unit-тестов.
