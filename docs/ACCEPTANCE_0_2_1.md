# Приёмка MVP 0.2.1 (на Windows)

## Автоматическая проверка

В каталоге `kompas_mvp` выполнить в PowerShell:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Ожидается `Ran 27 tests`, `OK`, затем открытие http://localhost:8501. Если `.venv` ещё не существует, создать окружение и установить `requirements.txt` по README.
