## Открытые решения
- Выбор доступной модели OpenAI и проверка качества/стоимости реальных запросов; K-034 реализует Responses API без включения в UI.
- Размещение публичного демо и хранение SQLite в облаке (для облачного хостинга постоянство локального диска не гарантировано).
- Реальный формат хранения согласия и удаления данных.
- Достаточность имеющихся данных об университетах для пользовательской демонстрации.

Правило изменений: существенное изменение архитектуры фиксировать новой строкой с датой, причиной и последствиями.
