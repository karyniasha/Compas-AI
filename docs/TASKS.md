## P1 — полезные усиления после P0
- [ ] Свободные ответы вместо только выбора вариантов.
- [ ] Генерация уточняющего вопроса с контролируемой рубрикой.
- [ ] Динамическая визуальная карта решения с альтернативами и причинами неопределённости.
- [ ] Измерение изменения качества аргументации до/после.

## Не делать до закрытия P0
- Полноценный веб-скрейпинг проходных баллов всех вузов в реальном времени.
- Сложные multi-agent-фреймворки.
- React/FastAPI-переписывание.
- Большую базу непроверенных профессий и университетов.

## Определение «готово»
- код запускается после чистой установки;
- тесты проходят;
- все основные маршруты можно завершить;
- ни один подтверждённый факт не лишён ссылки/даты;
- отчет экспортируется;
- презентация демонстрирует ценность без устных пояснений;
- файлы работы успешно поданы.
