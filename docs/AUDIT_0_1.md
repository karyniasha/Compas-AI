# Аудит MVP 0.1 и объём MVP 0.2

Дата: 22.10.2026. Основа: `kompas_project_package_1_0.zip`. Исполнено без переписывания архитектуры.

## Исходное состояние (до изменений)

- Структура: `app.py` (Streamlit), `kompas/core.py` (детерминированные правила), `tests/test_core.py`, документы.
- Три сценария (`history`, `internship`, `onboarding`), всего 11 кейсов (5+3+3), Markdown-экспорт.
- Пять исходных тестов прошли на Python 3.13.5 (`python -m unittest discover -s tests -v`).
- На проверочной машине пакет `streamlit` отсутствовал. Подтверждённого полноценного браузерного запуска **нет**.
- Информация о вузах была встроена в `app.py` как Markdown, без дат в реестре и семантики статусов.

## Проверки 0.2

- `python -m unittest discover -s tests -v`: 18/18 пройдено.
- `python -m compileall -q .`: пройдено.
- Тестируются три сквозных маршрута через ядро, год 2027/2026, обязательные ссылки и даты, неверные URL, неизвестная стоимость, локальный адаптер.
- Headless smoke-тесты `app.py` выполняются с **заглушкой Streamlit**, не доказывают корректность настоящей установки, рендера или поведения браузера.
- Попытка установки Streamlit: неуспешна из-за DNS/сетевой недоступности каталога пакетов. Ручная UI-проверка должна проводиться на машине автора.

## Граница готовности

MVP 0.2 является проверенной на уровне кода сборкой и подготовлен к локальному запуску после установки зависимостей. Фраза «проверено в браузере» будет допустима только после ручного открытия интерфейса, маршрута Георгия, проверки каждого информационного раздела и загрузки отчёта.

Предпочтение до конца октября: закрыть устойчивую демонстрацию, а не добавлять сложную инфраструктуру без тестового доказательства.
